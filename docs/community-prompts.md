## Pemeriksaan

Keempat-empat hasil diperiksa secara visual. Watak penuh, wajah dan uniform konsisten dengan set projek; lencana bintang rekaan, tiada senjata atau lambang rasmi. Helikopter diparkir tanpa putaran rotor. Set peralatan mempunyai sembilan objek berasingan; gari kartun hanyalah objek kecil tidak dipakai dan tidak melibatkan orang. Ketiga-tiga pose berukuran 1536 × 1024; set peralatan sebenar 1254 × 1254 (saiz keluaran alat). Semua PNG mempunyai Format32bppArgb dan piksel alfa sifar pada sampel latar, disahkan melalui System.Drawing tanpa mengubah fail.
